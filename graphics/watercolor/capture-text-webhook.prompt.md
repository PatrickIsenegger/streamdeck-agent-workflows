## Prompt

```text
Use case: stylized-concept
Asset type: watercolor repository graphic for GitHub README and workflow documentation
Primary request: Create a watercolor-style illustration of a Stream Deck workflow where pressing a button opens a small text-capture modal on a laptop, then sends the captured note to a webhook endpoint.
Scene/backdrop: A calm desk setup viewed slightly from above. A Stream Deck with one highlighted capture button sits beside a laptop. On the laptop screen is a simple modal window with blank text lines and a send/check mark action. A subtle arrow-like flow leads from the modal toward a small webhook/cloud endpoint icon. No readable UI text.
Subject: Stream Deck capture button, modal text entry, webhook delivery, reviewable automation workflow.
Style/medium: editorial watercolor illustration on textured paper, soft pigment granulation, restrained ink outlines, handmade and warm, matching a personal technical blog visual style.
Composition/framing: landscape 16:9, enough margin for README layout, central focus on Stream Deck button and laptop modal, simple clear flow.
Lighting/mood: practical, quiet, trustworthy, warm natural desk light.
Color palette: off-white paper, graphite, muted teal, rust accent, pale blue, soft green, small warm yellow highlight on the capture key.
Constraints: no logos, no brand marks, no readable text, no watermarks, no photorealism, no futuristic neon. The Stream Deck should be recognizable as a generic customizable button grid without copying branding exactly.
Avoid: clutter, dense text, corporate stock illustration, glowing sci-fi interface, exact product logos.
```
