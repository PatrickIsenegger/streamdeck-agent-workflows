# Claude Code Instructions

This repository manages Stream Deck exports and icon sources.

## Rules

- Do not edit live Stream Deck application data.
- Preserve exported originals.
- Put reviewed outputs in `profiles/reviewed/`.
- Keep visual changes separate from action behavior changes.
- Update `inventory/buttons.md` after profile or icon changes.
- Summarize all behavior-affecting changes explicitly.

## Checks

Run relevant local checks when available. If you cannot run them, say what remains unverified.
